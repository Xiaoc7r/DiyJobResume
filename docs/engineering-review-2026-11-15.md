# 编辑器审查与性能优化

## 2026-11-23 高频输入复查（基线 63ce782）

本轮沿用实际热点优先的审查方式，重点检查区块长按排序、侧栏宽度调整、图片移动/缩放，以及这些操作与文档/模式切换的生命周期。未修改界面、默认内容、依赖、协议或 README。

| 指定场景 | 基线 | 本轮 |
| --- | --- | --- |
| 同一帧内连续 100 次区块移动，落点行扫描次数（单元复现） | 100 | 1 |
| 同一落点连续两批移动，重复写入高亮 class 的次数 | 每次移动均移除并重新添加 | 只在落点元素变化时写入 |
| 浏览器中同帧连续 100 次校徽移动并松手，纸张几何读取次数 | 每次移动读取一次 | 1；最终坐标保留 |

- 把侧栏与图片手势的事件绑定、帧合并、末次提交和释放抽到共用的 `trackPointer`；区块排序共用同一个末次指针采样器。每个手势最多保留一个事件和一个动画帧，不建立常驻轮询、无界队列或额外缓存。
- 松手立即处理尚未绘制的最后一次移动，不依赖下一帧，也不使用可能缺省的松手坐标替换落点。取消、失焦、Escape、丢失捕获或卸载会释放监听器与待执行帧；文档/模式切换在布局清理阶段取消旧图片/侧栏会话。
- 区块排序保留快速点击/选择文字的原生行为与长按阈值，落点仍按当帧实际几何计算，不缓存可能因滚动/排版而过期的坐标。边缘自动滚动最多每帧走一步，避免鼠标高采样率放大滚动速度。
- 忽略其他指针的移动/结束事件；捕获不可用、节点已移除或浏览器已回收指针时安全清理。图片移动/缩放维持原有尺寸边界、坐标公式及每次手势一条撤销记录。

验证包含 197 项单元测试、格式检查、生产构建与 56 项全量浏览器回归，覆盖三种输入路径、撤销/重做、图片跨模式坐标、取消和窄屏。所有数值均是上述指定输入的工作量计数，不代表全站统一提速百分比；未改变可见画布分辨率、存档格式或文字型 PDF 输出。

## 2026-11-22 第二轮资源复查（基线 7890837）

再次追踪四模式的入口/加载、文本与行号、分页/模板装饰、画布与拖拽、图片/取色、历史/保存、字体/导出、引导与主题的生命周期。现有解析、校验、数据恢复、交互和可见画布清晰度保持；本轮修改集中在有重复工作证据的路径，不为重构而改变所有模块。

| 路径与验证场景 | 基线 | 本轮 |
| --- | --- | --- |
| 自由稿修改模板装饰后，简单模式连续 3 次缩放；SVG 缓存键序列化次数 | 6 | 0 |
| Markdown 连续 6 次内容变更，尺寸监听器总创建数 | 7 | 1 |
| 包含 400 个 SVG 图形的字体发现阶段；样式读取次数 | 404 | 3 |
| 批量读取 100 个尚未缓存的字体文件；并发峰值 | 100 | 不超过 6 |
| 字体 Data URL 缓存 | 无保留预算 | 最多 96 项、8 MB，超预算结果不长期缓存 |
| DPR=3 时，794×1123 页的 SVG 编码临时位图尺寸 | 2382×3369 | 794×1123 |

最后一项只影响 SVG 编码用的离屏画布：SVG 使用原尺寸、文字和矢量坐标，可见自由画布的像素密度、PNG 输出倍率以及文字型 PDF 未改变。该临时位图的像素预算降低约 89%，不等于全应用内存降低 89%。其他计数也是各自场景的操作次数，不作为全站统一提速比例。

实现与失效规则：

- 普通预览只在原生页面、模板装饰集合或模板标识改变时重新组合图层。缓存留在不可变文档的 React 渲染边界；没有缓存自由画布内部可变的页面模型，因此跨页移动、编辑、撤销和导出仍使用最新数据。
- Markdown 行号的 ResizeObserver、滚动和字体监听按编辑器生命周期订阅。文字变化仍立即测量未命中行；宽度/排版上下文或字体加载变化会重新测量。重复的初始尺寸通知和不变行号布局不再创建镜像 DOM 或重复更新状态。
- 字体嵌入从导出代码中分离，PNG、SVG 与取色共用下载/缓存逻辑。保留 HTML 节点以支持 CSS 生成内容，保留 SVG text/tspan/textPath 的字体发现，跳过不渲染字形的 SVG 几何节点。Unicode 码点排序后用二分查询字体范围，保留通配范围、边界和补充平面字符的匹配规则。
- 字体读取共享待完成请求并限制并发，失败可重试，30 秒网络超时释放读取槽位。只接受同源字体资源，保留中文和字体子集嵌入；8 MB 是缓存保留预算，不是整个导出过程的瞬时内存上限。

验证：180 项单元测试、格式检查、生产构建；53 项全量浏览器回归。新增检查覆盖改过的模板装饰持久化、Markdown 长行/增删/缩放、HTML/SVG 字体、Unicode 范围、字体失败/超时/按条数与字节回收、高 DPR 下的临时画布尺寸。PR CI 对最终提交重新执行全部检查；README、协议、依赖和界面设计均不改动。

## 2026-11-22 全流程复查

按 [Ponytail](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md) 及其 audit/review 规则追踪入口、数据、生命周期和失败处理；只拆实际职责，不引入框架、运行时依赖或推测性的插件层。基线为 `ac44679`。

### 本轮改动

- 自由画布按内容变更失效 SVG 缓存：添加、删除、编辑、拖拽、缩放元素、旋转、分组选择、换页及纸张尺寸改变均更新；预览缩放、网格、工具切换复用现有图层。局部预览与主画布继续共用同一份矢量结果。
- 画布快照复用一次 `canvas.toObject()` 的结果，按导出顺序映射对象，不再为图片重复序列化，也不再逐个扫描全表匹配模板装饰。导入对象即使 ID 重复，也不会因此丢失原生元素。图片高级编辑仍原子转为原生对象，备份中不重复存储。
- 换页/卸载取消旧绑定加载。复制以最后一次请求为准，异步粘贴、上传和图标插入只作用于发起操作的页面；过期或部分失败的对象会释放。完成复制后仍允许主动粘贴到另一页。
- 取色复用已有有界异步缓存：最多保留一页，缓存预算 64 MB，超出预算的结果不长期保留。旧页面捕获不会覆盖新目标，取消后不再回填颜色，连续点击只提交一次。指针和键盘切换调色板都会取消旧取色器。
- AI 界面按需加载；历史存取与界面/请求逻辑分离。关闭面板会中止连接测试，并避免卸载后的状态回写。
- 同一份存档不重复写入；未改动的简历不刷新时间戳。外部存档变化时校验并合并不同简历的修改；同一简历有冲突或被外部删除时，拒绝覆盖、保留当前编辑内容并提示下载备份。损坏存档仍先备份，备份/配额失败仍上抛。
- 保持 TypeScript 严格检查，统一源代码、测试和配置的 Prettier 格式，并将格式检查加入 PR CI。修正一处永远等于自身的测试，改为验证已摘要对话不会再次发出请求。

### 测量与边界

同机 Edge、1800×1200、生产构建；先等待字体、画布控件与保存就绪。以下是指定操作的实测，不是全网站或所有设备的统一提速承诺。

| 场景 | 基线 | 本轮 |
| --- | --- | --- |
| 默认示例连续 3 次预览缩放 | 12 次图片源读取 | 0 次 |
| 326 个原生元素、连续 24 次预览缩放 | 576 次图片源读取 | 0 次 |
| 同一压力场景的脚本执行 CPU 时间，两轮 ABBA 顺序 | 293 / 284 ms | 208 / 211 ms |
| 未打开 AI 时的入口 JS，未压缩 | 约 670 KB | 约 637 KB |

压力场景平均脚本执行时间减少约 27%；总任务时间和交互延迟有波动，不据此宣称统一帧率提升。未降低画布分辨率或改变文字型 PDF。64 MB 是取色缓存保留预算，不是整个应用或正在捕获的临时内存上限。现有 SVG、行测量、文字解析、撤销历史的预算继续生效。

`localStorage` 的逐次读写不是跨标签原子事务；本轮提供已观察版本的冲突检测与独立条目合并，不将其描述成多人实时协作或线性一致存储。大纸张、高缩放、多图片的瞬时内存仍取决于浏览器，不能承诺所有合法尺寸的固定资源消耗。

## 已处理的问题

| 路径 | 发现 | 处理与失效条件 |
| --- | --- | --- |
| 分页 | 输入后重复测量未改变的行 | 为每个测量宿主缓存行高；文字、类型、序号、续页和局部样式参与键；纸宽、模板、全局设置、字体加载等变化清空缓存。分页算法与尺寸精度不变。 |
| Markdown | 相同内联文本重复解析 | 复用不可变 HTML 字符串；限制缓存条数及总字节，超大项目不缓存。编辑 DOM 从不复用。 |
| 行号 | 每次输入创建全部测量节点 | 只批量测量新增、变化的行；宽度及字体参数参与键，字体加载后清空，滚动同步保留。 |
| 图层 | 普通重渲染也序列化整份图片与对象 | 图层组件按不可变页面引用复用，画布发布新页面时仍重新生成 SVG。 |
| 存档 | 连续保存反复解析并校验同一份旧存档 | 记住刚成功写入的完整字节；外部内容变化仍校验，损坏内容仍先备份，备份或写入失败仍向上抛出。 |
| 自制模板 | 每行样式解析重复查找表头；修改时再次整体序列化草稿 | 按文档建立一次样式索引，保留逐行覆盖优先级；使用不可变更新与画布原有的变更提交。 |
| 界面 | 侧栏连续拖动同步写入偏好 | 合并短时间偏好写入，并在离开页面时刷新。简历正文保存机制独立。 |

`SourceToolbar`、`NumberField`、`useAppearance`、内联颜色协议、行测量和有界缓存各自独立。简单编辑与 Markdown 共用工具栏、选择工具和调色板，避免同一功能维护两套实现。

## 颜色与安全边界

显式文字颜色格式：`<span style="color:#1059a5">文字</span>`。保留链接地址、标题、列表、列结构、加粗等信息。显式颜色优先于主题、正文和链接颜色，在自由预览及导出中保持。

只识别经过校验的十六进制颜色 span；不开放任意 HTML、CSS、脚本或资源地址。限制颜色嵌套深度，重复改色替换原颜色。跨段应用颜色按原有行拆分，不移动 React 管理的行容器。

## 视觉与切换

- 紫图使用标题中线装饰，保留原行高与正文位置。
- 样式组位于左侧，五个操作按钮整体位于工具栏几何中心；窄窗口自动换行。
- 深色界面保留日间的边框显示规则：透明控件保持透明，悬停后才出现灰色反馈。
- 主题切换从按钮中心按圆形半径扩展，最远角距离决定终点，460ms 缓动；纸张使用独立的静止过渡层。连续点击取消旧动画，以最后一次选择为准。减少动态效果、API 不可用或失败时直接切换。

## 验证

原有与新增单元测试、浏览器回归覆盖编辑删除、跨段选择、格式、颜色、撤销、六模板尺寸与图标、模板制造、模式往返、刷新、图片和文字型 PDF 导出、窄屏、深色模式、连续切换和减少动画效果。

本机 Edge、1800×1200、同一份 182 行样稿，连续 12 次修改，测量输入事件到随后两帧更新：优化前中位数 50.3ms，优化后 16.7ms。该结果用于同机对比，不作为其他设备或所有操作的性能承诺。构建依赖不变。
