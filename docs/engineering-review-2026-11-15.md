# 编辑器审查与性能优化

检查范围：结构化文本、富文本与 Markdown 往返，分页测量、模板样式、自制模板、自由画布与图层，存档与恢复，自定义 CSS 与资源校验，导出、夜间界面、缩放和侧栏。

## 已处理的问题

| 路径 | 发现 | 处理与失效条件 |
| --- | --- | --- |
| 分页 | 输入后重复测量未改变的行 | 为每个测量宿主缓存行高；文字、类型、序号、续页和局部样式参与键；纸宽、模板、全局设置、字体加载等变化清空缓存。分页算法与尺寸精度不变。 |
| Markdown | 相同内联文本重复解析 | 复用不可变 HTML 字符串；限制缓存条数及总字节，超大项目不缓存。编辑 DOM 从不复用。 |
| 行号 | 每次输入创建全部测量节点 | 只批量测量新增、变化的行；宽度及字体参数参与键，字体加载后清空，滚动同步保留。 |
| 图层 | 普通重渲染也序列化整份图片与对象 | 图层组件按不可变页面引用复用，画布发布新页面时仍重新生成 SVG。 |
| 存档 | 连续保存反复解析并校验同一份旧存档 | 记住刚成功写入的完整字节；外部内容变化仍校验，损坏内容仍先备份，备份或写入失败仍向上抛出。 |
| 自制模板 | 每行样式解析重复查找表头；修改时再次整体序列化草稿 | 按文档建立一次样式索引，保留逐行覆盖优先级；使用不可变更新与画布原有的变更提交。 |
| 界面 | 侧栏连续拖动同步写入偏好 | 合并短时间偏好写入，并在离开页面时刷新。简历正文保存机制独立。 |

`SourceToolbar`、`NumberField`、`useAppearance`、内联颜色协议、行测量和有界缓存各自独立。简单编辑与 Markdown 共用工具栏、选择工具和调色板，避免同一功能维护两套实现。

## 颜色与安全边界

显式文字颜色格式：`<span style="color:#1059a5">文字</span>`。保留链接地址、标题、列表、列结构、加粗等信息。显式颜色优先于主题、正文和链接颜色，在自由预览及导出中保持。

只识别经过校验的十六进制颜色 span；不开放任意 HTML、CSS、脚本或资源地址。限制颜色嵌套深度，重复改色替换原颜色。跨段应用颜色按原有行拆分，不移动 React 管理的行容器。

## 视觉与切换

- 紫图使用标题中线装饰，保留原行高与正文位置。
- 样式组位于左侧，五个操作按钮整体位于工具栏几何中心；窄窗口自动换行。
- 深色界面保留日间的边框显示规则：透明控件保持透明，悬停后才出现灰色反馈。
- 主题切换从按钮中心按圆形半径扩展，最远角距离决定终点，460ms 缓动；纸张使用独立的静止过渡层。连续点击取消旧动画，以最后一次选择为准。减少动态效果、API 不可用或失败时直接切换。

## 验证

原有与新增单元测试、浏览器回归覆盖编辑删除、跨段选择、格式、颜色、撤销、六模板尺寸与图标、模板制造、模式往返、刷新、图片和文字型 PDF 导出、窄屏、深色模式、连续切换和减少动画效果。

本机 Edge、1800×1200、同一份 182 行样稿，连续 12 次修改，测量输入事件到随后两帧更新：优化前中位数 50.3ms，优化后 16.7ms。该结果用于同机对比，不作为其他设备或所有操作的性能承诺。构建依赖不变。
