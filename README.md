# DiyJobResume

一个使用免费、源码公开、无需登录的自由在线简历编辑器。  
选模板、填内容、调排版，数据均在浏览器本地处理。

【 [点击即用](https://xiaoc7r.github.io/DiyJobResume/) 】

支持三种模式编辑简历：

小白简单编辑模式，.md编辑模式，以及画板自由编辑模式。

支持接AI api用于简历智能排版优化，可diy程度极高。


## 🛠️ 本地运行

需要安装 Node.js。

```bash
git clone https://github.com/Xiaoc7r/DiyJobResume.git

cd DiyJobResume

npm install

npm run dev
```
