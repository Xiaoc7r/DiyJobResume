# 简历工坊 · DiyJobResume

像搭积木一样做简历，也可以自由排出自己的样子。

**[打开即用 →](https://xiaoc7r.github.io/DiyJobResume/)**

暖白、陶土色、克制留白的编辑工作台。无需注册，默认提供虚构示例，所有简历内容只存储在当前浏览器。

## 第一次使用

1. 选一套模板，快速得到完整简历。
2. 点击纸上的模块，在右侧填写自己的信息；也可以双击文字直接编辑。
3. 在「拼模块」里添加个人信息、教育、实习、项目、技能和奖项，选择留白、线条或柔和样式。
4. 打开「自由排版」，拖动模块、拖右下角改变尺寸，添加照片、文字、分割线和色块。
5. 点击「导出简历」，在系统打印窗口选择「另存为 PDF」。建议 A4、100% 缩放、关闭页眉页脚、开启背景图形。

## 当前边界

这是可使用的最小版本，不是完整的 Word 或 CanvasEditor 替代品。文本目前按模块设置样式，没有字级富文本、组合旋转或跨页自动拆分长段落。拖动模块后可自由重叠，需要自行检查；长模块会提示溢出，可增高、拆成多个模块或放到新页。整套模板与一键整理会重新安排模块位置。

PDF 使用浏览器的打印能力，显示系统打印窗口，不调用服务器；不同系统字体和打印设置可能产生差异，请检查最终预览。浏览器数据清理会移除草稿，重要版本请下载备份。没有云同步、账号、AI 或 PDF/Word 内容导入；「导入」仅接受本站 JSON 备份。最多 20 页、100 个模块，单张图片 1.5 MB。

## 本地开发

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
npm test
npm run build
```

核心：React + TypeScript + Vite，Lucide 图标。`src/model.ts` 管理文档模型、历史与模板排版；`src/App.tsx` 管理工作台交互；`src/styles.css` 包含响应式和打印样式。锁文件固定安装版本。

## 发布

仓库 Settings → Pages → Build and deployment 选择 **GitHub Actions**。推送 `main` 自动运行测试并发布。构建使用相对资源地址，适配仓库子路径。

## 设计来源

自由画布、图形模块和属性面板的交互参考 [WindRunnerMax/CanvasEditor](https://github.com/WindRunnerMax/CanvasEditor)，代码为本项目独立实现，使用 DOM 图层保留原生文本与打印能力。界面采用温暖、简洁的设计语言，不隶属于 Claude 或 Anthropic。模板内容均为虚构示例。

字体使用用户系统字体，不请求外部字体服务。没有分析脚本、第三方内容上传或服务端简历存储。
