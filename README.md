# 简历工坊 · DiyJobResume

**[打开即用 →](https://xiaoc7r.github.io/DiyJobResume/)**

写内容，选风格，得到一份白色 A4 简历。无需注册，内容只保存到当前浏览器。

## v0.2

- **正式简历版式**：蓝色细线、黑色横线、黑色标签三套风格，参考用户提供的版式截图独立实现。切换风格保留内容。
- **自动分页**：按实际字体和可用宽度测量正文，内容增加自然续页，减少自动收页；超长段落可跨页；标题尽量与后续内容保持在同页。
- **左侧统一编辑**：简单模式显示富文本；Markdown 模式编辑源文。左侧宽度可拖动调整，窄屏通过底部导航切换面板。
- **右侧模板与内容**：教育、实习、项目、技能、奖项提供两列、三列、段落、分类要点等内容组织方式，自动继承当前整套风格。
- **纸上直接编辑**：单击输入并定位左侧；双击显示拖动手柄，拖动到目标段落之前。拖动板块标题会同时移动其内容。Enter 添加下一段，Shift+Enter 段内换行。
- **统一排版**：顶部缩放滑杆、正文色、主题色、四向页边距、字体；间距面板调整姓名、板块、经历、正文、列表的上间距、下间距和字号。
- **照片与校徽**：上传 PNG/JPG/WebP，拖动位置、调整尺寸、删除和选择所在页；表头区域图片会预留高度，其他位置需自行检查遮挡。
- **本机保存与备份**：撤销重做、JSON 备份导入导出、Markdown 导入导出。v0.1 文字和图片自动迁移，原始草稿 key 保留。
- **文字 PDF**：点击导出 PDF，在浏览器打印窗口选择“另存为 PDF”。A4、100% 缩放、关闭页眉页脚，开启背景图形。

## Markdown 约定

```md
# 炒肉多
138 0000 2468 | xxiaocr@gmail.com
## 教育背景
### 示例大学 · 计算机科学与技术 | 2021.09 — 2025.06
本科 · 学位与课程
## 项目经历
### 2024.01 — 2024.06 | 项目名称 | 核心开发者
- **贡献：**说明你具体完成的工作。
- 技术栈：`Java` `MySQL`
```

支持三个标题层级、普通段落、无序列表、经历中的 ` | ` 分列、`**加粗**`、`*斜体*`、行内标签、HTTP(S)/mailto 链接。不执行 HTML 或脚本。空白源文行不生成空白纸页，留白通过排版设置控制。

三种编辑入口共享同一个内容模型，照片与样式在 JSON 中保存；Markdown 文件仅保存内容。备份导入可撤销。

## 字体与隐私

随网站自托管 Noto Sans SC、Noto Serif SC、Nunito 三种 OFL 字体，浏览器按字符范围加载字体分片。Noto 中文字体与 Adobe 思源系列同源，界面使用其实际字体名，不分发微软雅黑、苹果方正等商业字体。[字体来源与许可证](FONT_LICENSES.md)。

示例姓名、邮箱采用用户指定值，电话与其他经历为虚构示例。无账号、云同步、AI 请求、统计追踪或服务端简历存储。清理浏览器数据会清除当前草稿，请保存 JSON 备份。

## 当前边界

这是面向简历的内容流编辑器，不是任意图形画布或完整 Word。正文拖动改变文档顺序；图片可以自由定位。支持本站约定的 Markdown 子集，不支持任意 Markdown 表格、嵌套列表或 HTML。复杂行内格式跨越分页边界时可能在边界处显示原始标记，源文会保留。照片不创建额外空白页；所属页消失时显示在最后一页。单张图片不超过 1.5 MB，最多 10 张；导入内容最多 15 万字符、2000 行。

浏览器打印中的字体与文本提取空格处理可能因阅读器不同而略有差异；导出前检查打印预览。旧版色块、分割线、自由坐标与单块样式不迁移到正文，旧版 JSON 可另存保留。

## 开发与发布

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
npm test
npm run build
```

React + TypeScript + Vite。`flow.ts` 负责内容、迁移、分组与分页，`render.ts` 负责安全行内渲染，`Studio.tsx` 负责编辑联动，`studio.css` 负责界面与打印。没有保留旧版图层面板、手动加页、编辑/自由排版开关。

GitHub Pages 采用 GitHub Actions；推送 `main` 自动测试、构建、发布。交互参考 [CanvasEditor](https://github.com/WindRunnerMax/CanvasEditor)，代码独立实现。
