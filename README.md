# DiyJobResume

一个个人使用免费、源码公开、无需登录的在线简历编辑器。  
选模板、填内容、调排版，数据均在浏览器本地处理。

【 [点击即用](https://xiaoc7r.github.io/DiyJobResume/) 】

## 🛠️ 本地运行

需要安装 Node.js。

```bash
git clone https://github.com/Xiaoc7r/DiyJobResume.git

cd DiyJobResume

npm install

npm run dev
```
